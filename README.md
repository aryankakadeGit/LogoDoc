# LogoDoc
# AI-Powered Logo Analysis Platform

A web application that analyzes company logos, evaluates their design quality, and provides structured scores and suggestions for improvement using AI and image analysis.

## Features

- Logo upload and analysis
- Overall logo quality score
- Color harmony and contrast evaluation
- Typography and readability assessment
- Visual composition and simplicity analysis
- Brand relevance and distinctiveness evaluation
- Scalability and versatility assessment
- Design feedback and improvement suggestions

## Tech Stack

- **Frontend:** React.js / Next.js, HTML, CSS, Tailwind CSS
- **Backend:** Python, FastAPI
- **Image Processing:** OpenCV, Pillow
- **AI Integration:** Vision-capable LLM API
- **Data Format:** JSON
- **Version Control:** Git, GitHub


## How It Works

1. Upload a company logo.
2. Process the image for analysis.
3. Evaluate the logo across selected design parameters.
4. Generate scores and feedback.
5. Display recommendations for improvement.

## Installation

Clone the repository:

```bash
git clone <YOUR_REPOSITORY_URL>
cd <PROJECT_DIRECTORY>
```

Install the required dependencies according to the project's configuration.

Configure the required AI API key using environment variables.

Run the backend and frontend using the commands specified in their respective project configurations.
